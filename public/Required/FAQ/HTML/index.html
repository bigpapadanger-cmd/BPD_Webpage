Frequently Asked Questions

Quick answers about the features currently available on BPD Gaming Network.

What is my BPD display name?

Your BPD display name is the name shown for your site account. It is separate from your Epic Games, Discord, Google, or other linked-provider names.

How do I link an account provider?

Sign in to your BPD account, open Account, and use the provider-linking controls there. A linked provider and a currently authorized provider are separate states; the page will offer a verification action if authorization needs refreshing.

Why do I need a Rocket League profile?

A completed Rocket League profile enables the Rocket League features that require registration. The Rocket League hub remains visible, and it will explain when profile setup is needed.

Can I choose whether my profile is discoverable?

Yes. In your Rocket League profile settings, “Allow users to find my profile” controls Find Players visibility independently from online-presence visibility.

What does “Recent MMR Change” mean?

It compares the latest stored MMR snapshot with the previous stored snapshot for each playlist. It is not a last-match result. If there is no previous capture, the page says so rather than showing a zero change.

How does scoreboard OCR work?

Submit a scoreboard image through Submit Match Results. OCR extracts values for review; values that need confirmation are shown for verification before the result is finalized.

Where can I share an idea?

Suggestions are separate from this FAQ. Open the Suggestions page to view approved ideas or, while signed in, submit and vote on suggestions.

Where do my appearance settings apply?

Theme, animation, and sidebar preferences are saved in this browser. They do not sync between devices.
