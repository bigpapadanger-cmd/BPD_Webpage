RLFOLDERSTRUCTURING CURRENT-STATE ORGANIZATION MAP
Snapshot: 2026-10-02
Project directory on disk: DomainData
Purpose: Codex navigation and orientation. This is descriptive only.

SYSTEM AT A GLANCE

Browser / public site
    public/index.html
        -> public/routes.js defines client-side page routes
        -> public/Framework/ supplies the shared shell, auth, layout, and router
        -> public/Global/, public/Required/, public/Tabs/, and public/ocr/
           supply route-specific HTML, CSS, and JavaScript
        -> browser code calls /api/* endpoints

Cloudflare Pages application
    wrangler.jsonc
        -> publishes public/ as the Pages output
        -> binds AUTH_SESSIONS and RL_STATS_CACHE (KV)
        -> binds OCR_TRAINING, OCR_STORAGE, and OCR_PROGRESS (R2)
        -> binds OCR_JOB_QUEUE as a queue producer
        -> binds OCR_GOOGLE_TRANSPORT to bpd-ocr-cloud-run-proxy
    functions/api/
        -> file-based /api/* request handlers
        -> delegates reusable work to functions/services/

OCR job path
    public/ocr/ and shell OCR modules
        -> functions/api/ocr/jobs/submit_job.js
        -> OCR_STORAGE / OCR_PROGRESS and OCR_JOB_QUEUE
        -> workers/ocr-job-consumer/
        -> Pages /api/ocr/jobs/process_job
        -> internal OCR_GOOGLE_TRANSPORT Service Binding (shared-secret gated)
        -> workers/ocr-cloud-run-proxy/
        -> Google mTLS STS / IAM ID token -> fixed Cloud Run OCR service
        -> ocr_cloudData/ Flask service and OCR pipeline
        -> result/progress endpoints in functions/api/ocr/jobs/
        -> browser OCR monitor/results modules

Rocket League background path
    Pages functions and site UI
        <-> Supabase, external MMR service, and AUTH_SESSIONS
        <-> workers/rl-presence-monitor/
            - scheduled presence checks
            - hourly due-aware MMR/profile/stats/club refresh
            - scheduled Taskboard summary
            - /health and authorized /wake endpoints

PRIMARY NAVIGATION INDEX

1. public/ - browser-delivered site
    Assets/       Images, logos, and currently empty media/font holders.
    Framework/    Shared authentication, banner, shell fragments, routing,
                  navigation, master CSS, and global OCR runtime modules.
    Global/       Site-wide pages: home/dashboard, account, login, settings,
                  public suggestions, links, ads, errors, and admin pages.
    Required/     About, curated + published FAQ with question workflow, Privacy Policy, and Terms.
    Tabs/         Game sections for Rocket League, Minecraft, and Ark.
    ocr/          Submit-match-image page and its browser-side workflow.
    scripts/      Shared API routing/connection and cache/sitemap utilities.

2. functions/ - Cloudflare Pages server-side API
    api/          Route handlers whose paths map to /api/* URLs.
    services/     Reusable business, provider, storage, and integration logic.

3. ocr_cloudData/ - deployable Python OCR processor and local OCR data
    ocr/          Production OCR pipeline by configuration, preparation,
                  layout, readers, rules, and runtime support.
    debug/        Local diagnostic entrypoint.
    training/     Digit/bar reference images grouped by class.
    output/       Generated diagnostic images and JSON reports.
    root files    Flask entrypoint, container and deployment configuration,
                  and Python requirements.

4. workers/ - independently deployed Cloudflare Workers
    ocr-cloud-run-proxy/  Pages-bound Cloud Run transport; custom domain is
                          secret-gated and not called by browser code.
    ocr-job-consumer/     Consumes queued OCR jobs and performs cleanup.
    google-mtls-diagnostic/ Temporary manual WIF/mTLS probes; not production.
    rl-presence-monitor/  Runs Rocket League and Taskboard automation.

5. Root configuration and support
    wrangler.jsonc        Pages deployment and resource bindings.
    package.json          Build, development, OCR/suggestion/route tests, and inventory scripts.
    scripts/              Generated Pages API/page/Worker route inventory builder.
    public/_redirects     Clean-route handling for the single-page shell.
    public/_headers       Static response-header rules.
    README.md, _README    Project/development notes.
    CNAME                 Custom-domain declaration.
    eng.traineddata       Tesseract English-language OCR data.
    Notes/                Operational notes and SQL/schema working material.

6. Local/generated infrastructure
    node_modules/         Installed JavaScript packages.
    .venv/                Local Python environment.
    .wrangler/            Local/generated Cloudflare build and state data.
    .ruff_cache/          Python lint cache.

PAGE ROUTE ORGANIZATION

Every route is rendered through the shared shell in public/index.html and
public/Framework/Shell/JS/router.js. public/routes.js selects a body fragment,
page module, sidebar, header/footer behavior, and route metadata.

Main/global routes
    /                         Shared shell body / main menu; authorized Admin shortcut is shown only after server access confirmation.
    /Dashboard                Global/Index personalized dashboard, separate from the public main menu.
    /Account                  Global/Account account management.
    /Login                    Global/Login authentication page.
    /About                    Required/About.
    /FAQ                      Required/FAQ.
    /Admin/FAQReview           Global/Admin/FAQ; question review/publishing, separate from Suggestions.
    /Settings                 Global/Settings; browser-local preferences, AdSense consent revocation, and signed-in BPD display-name editing with authoritative 30-day cooldown presentation.
    /Suggestions              Global/Suggestions; public approved ideas and signed-in submissions/voting.
    /Privacy                  Required/PrivacyPolicy.
    /TOS                      Required/TOS.
    /Error                    Global/404.

Rocket League routes
    /RocketLeague             Tabs/RocketLeague/Index; signed-in view uses persisted ranks, career totals, snapshot MMR changes, and up to 90 captures; public content explains current tools.
    /RocketLeague/Profile     Tabs/RocketLeague/Registration; onboarding/setup route, redirects established accounts to MyProfile.
    /RocketLeague/MyProfile   Private settings editor and destructive RL-only profile deletion; BPD account session is retained, while Epic is unlinked and RL participation/notification records may be removed.
    /RocketLeague/FindPlayers Public opt-in search through Pages API; styled responsive cards, three compact ranks, neutral unknown presence.
    /RocketLeague/Player      Public-safe profile by public_profile_id; hidden profiles unavailable.
    /RocketLeague/Shop        Public cached shop carousel through the DomainData API; no provider call on page view.
    /RocketLeague/MatchHistory Auth-gated status page; match-by-match history for arbitrary linked players is unsupported; MMR captures are not matches.
    /RocketLeague/Leaderboards, /MatchResults
                              Public shell status pages; no fabricated standings or results.
    /RocketLeague/WeeklyMatches, /MyMatches, /PrivateMatches
                              Auth-gated shell status pages until verified scheduling/participant records are available.
    /RocketLeague/SubmitMatchResults
                              Auth-gated public/ocr submission workflow.
    /RocketLeague/ImageScanning
                              Compatibility redirect to /RocketLeague/SubmitMatchResults.

Other game routes
    /Minecraft                Minecraft landing page.
    /Minecraft/Mods           Minecraft mods page.
    /Minecraft/Announcements  Minecraft announcements page.
    /Ark                      Ark landing page.
    /Ark/Mods                 Ark mods page.
    /Ark/Announcements        Ark announcements page.

Administration routes
    /Admin                    Global/Admin/Home.
    /Admin/Taskboard          Global/Admin/TaskBoard and its multi-view modules.
    /Admin/WorkerStatus       Permission-gated diagnostics and Rocket League registry; Admin-only Force Rocket League Refresh; MMR / Skills, display-name Profile, and Player Stats are active; XP / Progression and Match History are inactive/unsupported.
        /api/admin/system-status/mmr-deploy
            Dedicated fixed-target MMR production workflow dispatch/status.
        /api/admin/rocketleague/force-refresh (admin.rocketleague.force-refresh)
    /Admin/PageSettings       Compatibility alias for the unified System Status page.
    /Admin/SuggestionReview   Pending suggestion moderation; admins and moderators only.
