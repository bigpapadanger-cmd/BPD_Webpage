PUBLIC/: BROWSER APPLICATION, PAGES, AND STATIC ASSETS
Snapshot: 2026-10-02

ROLE

public/ is the Cloudflare Pages build output configured by root wrangler.jsonc.
It is a client-rendered site shell: index.html starts the application, routes.js
describes pages, and Framework/Shell/JS/router.js loads shared and page-specific
fragments/modules without separate full-page HTML documents.

ROOT FILES

public/
+-- index.html       Application shell/entry document.
+-- routes.js        Route-to-title/body/module/sidebar/header/footer map.
+-- _redirects       Clean-route rewrites into the shell.

+-- sitemap.xml      Search-engine route listing.

+-- ads.txt          Advertising declaration.
+-- .assetsignore    Asset handling exclusions.

ROUTE-TO-FOLDER MAP

    /, /Dashboard         -> Framework shell and Global/Index
    /Account, /Login      -> Global/Account and Global/Login
    /Admin*               -> Global/Admin/Home and Global/Admin/TaskBoard
/RocketLeague/Profile -> Registration onboarding; established accounts redirect to /RocketLeague/MyProfile
/RocketLeague/MyProfile -> Private field-aware settings editor; full-save action fails closed on any unconfirmed RPC field
/RocketLeague/FindPlayers -> Public opt-in directory search and public profile links
/RocketLeague/Shop -> Cached Supabase shop snapshot; item artwork/section logos with BPD fallback; no provider call on page views
/RocketLeague/MatchHistory -> Auth-gated status page; arbitrary linked-player match history is unsupported
/RocketLeague/Leaderboards -> public cached global ranked snapshots; hourly refresh; SQL migration prepared but not applied
/RocketLeague/MatchResults, /WeeklyMatches, /MyMatches, /PrivateMatches -> Shell-integrated status pages until verified data workflows exist
    /RocketLeague*        -> Rocket League home/profile/discovery/feature pages plus public/ocr submission workflow
    /Minecraft*           -> Tabs/Minecraft
    /Ark*                 -> Tabs/Ark
    /About, /FAQ,
    /Privacy, /TOS        -> Required/*
    /Settings             -> Global/Settings
    /Suggestions          -> Global/Suggestions
    /Admin/PageSettings   -> compatibility alias for /Admin/WorkerStatus; legacy source folder is retained but not mounted
    /Admin/WorkerStatus  -> Global/Admin/WorkerStatus; unified system health and route diagnostics
    /Admin/SuggestionReview -> Global/Admin/Suggestions
    /Error                -> Global/404

The router loads the selected HTML body and JavaScript module, applies a master
CSS bundle selected by route family, injects the shared header/sidebar/footer,
enforces route authentication, and initializes the page module.
